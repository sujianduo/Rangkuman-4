Rangkuman Bahasa Mandarin
第一课内容概要

1. 书 : shū : buku
2. 笔 : bǐ : alat untuk menulis
3. 同桌 : tónɡ zhuō : teman semeja
4. 书包 : shū bāo : tas sekolah
5. 玩具 : wán jù : mainan
6. 本子 : běn zi : buku tulis
7. 尺子 : chǐ zi : penggaris
8. 这 : zhè : ini
9. 那 : nà : itu
10. 谁 : shéi : siapa

zhè shì xiǎo qiánɡ de bǐ 1. 这 是 小 强 的 笔 。 Ini adalah pensil Xiaoqiang. nà shì shéi de shū bāo 2. 那 是 谁 的 书 包 ？ Itu tas sekolah siapa? zhè shì mèi mei de wán jù 3. 这 是 妹 妹 的 玩 具 。 Ini adalah mainan adik perempuan. zhè shì wǒ de shū 4. 这 是 我 的 书 。 Ini adalah buku saya. nà shì shéi de běn zi 5. 那 是 谁 的 本 子 ？ Itu buku tulis siapa?
